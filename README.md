git学习

## 常用 Git 使用流程

1. 初始化与克隆
   - `git init`
   - `git clone <仓库地址>`
2. 查看状态
   - `git status`
   - `git log --oneline --graph --decorate`
3. 提交改动
   - `git add <文件名>` 或 `git add .`
   - `git commit -m "提交说明"`
4. 分支操作
   - `git branch`
   - `git checkout -b <新分支名>`
   - `git checkout <分支名>`
   - `git merge <分支名>`
5. 远程同步
   - `git pull`
   - `git push`
